# EJA Shopping Digital - React App

Aplicação web moderna para o EJA Shopping Digital, desenvolvida com React e Vite.

## 📋 Funcionalidades

- Landing page responsiva
- Links para Mercado Livre, Hotmart e redes sociais
- Botão WhatsApp flutuante
- Design moderno com gradientes
- Navegação intuitiva

## 🚀 Início Rápido

### Pré-requisitos
- Node.js (v16 ou superior)
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/emidio1jaciara2-code/EJA-app.git

# Acesse a pasta
cd EJA-app

# Instale as dependências
npm install
```

### Desenvolvimento

```bash
# Inicie o servidor de desenvolvimento
npm run dev
```

O app abrirá em `http://localhost:3000`

### Build para Produção

```bash
# Crie a versão otimizada
npm run build

# Preview da versão de produção
npm run preview
```
